throughout `src/` reference these by bare filename (e.g. "STRUCTURE.md §13",
"SECTIONS.md §2.16", "CHECKLIST.md Phase 13") — those references resolve to this
folder.

| Document | Scope |

| [SECTIONS.md](SECTIONS.md) | Per-section design and content specification |
| [CHECKLIST.md](CHECKLIST.md) | Phase-gated build checklist with gates |
| [SEO_AEO_GEO.md](SEO_AEO_GEO.md) | Search, answer-engine and generative-engine optimization |
| [Copywriting.md](Copywriting.md) | Voice, tone, and claim discipline |
